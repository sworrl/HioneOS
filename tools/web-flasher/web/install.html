HioneOS · Update & Flash

Plug your HiBy M500 into this computer over USB, connect it below, and one-click root or install HioneOS. No tools to install — everything runs in your browser.

⚠ Browser not supported

  • This installer needs WebUSB. Use desktop Chrome, Edge, or another Chromium browser over https. Firefox/Safari won't work.

Before you start

  • Unlock the bootloader first (one-time, wipes the device): boot to fastboot, then run fastboot flashing unlock (and fastboot oem unlock if prompted) on the device.
  • Get the M500 into fastboot mode and connect the USB cable directly to this computer (avoid hubs).
  • Installing HioneOS erases all user data. Rooting (init_boot swap) does not.
  • Don't unplug during flashing.
